3D Data Visualization Examples

Small demos showing how data prepared in SQL (SQL Server / Snowflake) can be exported as JSON and turned into interactive 3D charts in the browser with Three.js. All data here is fictional.

Revenue by Region & Month

3D bar grid: regions × months, bar height = revenue. Orbit with the mouse, hover a bar to see the value.

JSON feed · OrbitControls · Raycaster tooltips

Compensation by Business Unit

Stacked 3D columns of base salary, bonus and commissions per business unit, with a year filter.

Stacked bars · Filters · Legend

How the data flows

  1. SQL – a query or stored procedure aggregates the data (e.g. SELECT region, month, SUM(revenue) ... GROUP BY region, month).
  2. JSON – the result is exported as JSON (FOR JSON PATH in SQL Server, or an API endpoint). Here it is a static file in /public/data.
  3. Three.js – the page loads the JSON with fetch() and creates one 3D bar per row.
